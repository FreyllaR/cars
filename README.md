# Турбо Круг

Браузерные гонки в одном файле `index.html`, без сборки и библиотек. Откройте файл в браузере и играйте.

- Управление: **W / S** — газ и тормоз, **A / D** — руль, **Пробел** — ручник, **R** — вернуться на трассу, **Esc** — пауза, **M** — без звука.
- 4 бота-соперника, три уровня сложности.
- 5 трасс: Зелёная долина, Песчаный каньон, Снежный перевал (лёд), Ночной город, Вулкан (лава).
- Очки за место на финише и гараж с пятью машинами.
- Настройки: громкость, язык (русский / English), камера (сзади с наклоном / сверху).

Очки, машины, рекорды и настройки хранятся в `localStorage` браузера.
